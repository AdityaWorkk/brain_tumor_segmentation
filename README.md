# Brain MRI Tumor Segmentation Studio

U-Net (ResNet34) based brain tumor segmentation from MRI scans.

- Upload your own MRI scan or generate random samples (up to 15)
- Model achieves ~70.1% validation Dice score
- Predictions are for research/demo purposes only
